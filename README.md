# iTrucking Registration Portal

Multi-step registration site for iTrucking services.

## Pages

- `/` — Lead registration (new applicants)
- `/registration/` — Full registration (approved leads)

## Features

- Multi-step forms with progress bar
- 4 languages: English, Russian, Ukrainian, Spanish
- Responsive (mobile + desktop)
- File upload support
- Checkboxes, radio buttons, external links

## Tech Stack

HTML + Tailwind CSS (CDN) + Vanilla JS

## Local Development

Open `index.html` in a browser, or use Live Server in VS Code.
