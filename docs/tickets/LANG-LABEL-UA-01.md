# LANG-LABEL-UA-01 — украинский язык подписан «UA», а не «UK»

**Статус:** готово к ревью
**Дата:** 2026-10-29
**Ветка:** `TUTORIALS-REACT` (по просьбе: без новой ветки и без worktree)

## Задача

В выпадающем списке выбора языка в шапке сайта украинский язык подписан
«UK». Заменить подпись на «UA».

## Как было

- `src/components/Header.jsx` — список языков в шапке: `EN`, `RU`, `UK`,
  `ES`. Шапка общая для всех страниц, включая туториалы (`#/tutorials`).
- `src/components/LanguagePromptModal.jsx` — окно выбора языка при первом
  входе: у кнопки «Українська» короткая подпись `UK`.

## Решения

- Меняется **только подпись** (`label` / `shortLabel`). Код языка остаётся
  `uk` (ISO 639-1): по нему выбираются переводы в `translations.js`,
  украинская версия туториалов (`LANGS`, поля `uk`, `cover-uk.jpg`), и он
  сохранён у пользователей в `localStorage` (`itrucking-lang`). Смена кода
  сбросила бы выбранный язык и сломала туториалы.
- Подпись меняется и в окне выбора языка при первом входе, чтобы язык
  везде назывался одинаково.

## План

1. `Header.jsx` — `{ code: 'uk', label: 'UA' }`.
2. `LanguagePromptModal.jsx` — `shortLabel: 'UA'`.
3. Проверка: `npm run build`; в браузере — выпадающий список показывает
   «UA», выбор украинского переключает страницу и туториалы на украинский,
   окно первого входа показывает «UA», ошибок в консоли нет.

## Что сделано

- `src/components/Header.jsx` — подпись украинского в списке языков: `UA`.
- `src/components/LanguagePromptModal.jsx` — короткая подпись у
  «Українська»: `UA`.

## Проверка

- `npm run build` — без ошибок.
- Браузер (dev-сервер):
  - окно выбора языка при первом входе (очищен `itrucking-lang`):
    «Українська / UA»; выбор украинского сохраняет код `uk`, страница
    `#/` переключается на украинский;
  - шапка `#/`: в списке `EN`, `RU`, `UA`, `ES`, выбран «UA»;
  - `#/tutorials`: та же шапка с «UA», тексты и заголовок вкладки на
    украинском; переключение UA → EN → UA без перезагрузки работает;
  - мобильная ширина 375px и тёмная тема: «UA» в шапке читается, нет
    горизонтальной прокрутки;
  - ошибок в консоли браузера и в логах dev-сервера нет.
