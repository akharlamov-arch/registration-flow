# TUTORIALS-PAGE-01 — страница туториалов `portal.itrucking.pro/tutorials`

**Статус:** готово к ревью
**Дата:** 2026-10-22
**Ветка:** `MOBILE-VERSION` (по просьбе: без новой ветки и без worktree)

## Задача

Собрать в registration-flow страницу базы знаний (туториалов) для клиентов —
перенос статического сайта из репозитория
[`akharlamov-arch/tutorial.itrucking.pro`](https://github.com/akharlamov-arch/tutorial.itrucking.pro)
(один `index.html` + `assets/`).

Требование — **полное совпадение** с оригиналом: размеры, шрифты, окна,
тексты, кнопки, расположение всех элементов, и **полный перенос функционала**:

- шапка: логотип (светлый/тёмный), переключатель RU/EN, кнопка установки
  приложения (PWA, только iOS/Android), переключатель темы 🌙/☀️;
- заголовок «Клиентский портал iTrucking Pro» и поиск по заголовку/описанию
  с иконкой очистки;
- категории: Все, iTrucking Pro, OnRamp, Использование карт EFS,
  Программа скидок на шины;
- сетка карточек (9 туториалов) с картинкой, категорией, временем чтения
  и числом шагов (русские склонения «шаг/шага/шагов»);
- модальное окно туториала: главная картинка, вступление, шаги с
  картинками, примечаниями, советами, «Как это избежать», кнопки
  App Store / Google Play, блок «Редактирование пользователей»,
  заключение, рекомендации (случайные 2 из той же категории);
- переходы между туториалами по внутренним ссылкам (`#tutorial-N`);
- лайтбокс для картинок (клик по картинке → полноэкранный просмотр);
- окно инструкции по установке на iPhone/iPad и Android;
- футер: контакты, отделы, ресурсы, адрес, соцсети;
- закрытие окон по ×, клику по фону и Esc; тёмная тема запоминается.

## Решения по уточнениям

1. **Язык** — связан с приложением. Кнопки RU/EN как в оригинале, выбор
   общий с порталом (`itrucking-lang`). Тексты туториалов есть только на
   RU/EN, поэтому UK показывается как RU, ES — как EN. Если язык ещё не
   выбран — страница открывается на RU, как оригинал (без записи в
   `localStorage`, чтобы не навязывать язык остальному приложению).
2. **Кнопки App Store / Google Play** — оставить заглушки, как в оригинале
   (`href="#"`); реальные ссылки добавить позже.
3. **Адрес** — роут `#/tutorials` (HashRouter) + статическая заглушка
   `public/tutorials/index.html`, которая перенаправляет `…/tutorials` на
   `#/tutorials`.

## Решение

Новая страница `#/tutorials` — React-порт оригинала один в один: та же
разметка (те же классы и порядок элементов), тот же CSS, та же логика.

| Файл | Что внутри |
|---|---|
| [`src/pages/tutorials/TutorialsPage.jsx`](../../src/pages/tutorials/TutorialsPage.jsx) | Страница: шапка, поиск, категории, сетка карточек, лайтбокс, футер; состояние (язык, тема, фильтры, окна), Esc, блокировка прокрутки, `<head>` оригинала (иконки, `theme-color`) на время показа страницы |
| [`src/pages/tutorials/TutorialModal.jsx`](../../src/pages/tutorials/TutorialModal.jsx) | Окно туториала — блоки в том же порядке, что в `openTutorial()` оригинала; переходы по `#tutorial-N` через делегирование кликов |
| [`src/pages/tutorials/InstallModal.jsx`](../../src/pages/tutorials/InstallModal.jsx) | Кнопка 📱 (PWA) и инструкции установки для iOS/Android |
| [`src/pages/tutorials/content.js`](../../src/pages/tutorials/content.js) | 9 туториалов и строки интерфейса RU/EN — **сгенерированы скриптом из оригинального `index.html` дословно** (без ручного перепечатывания); пути к картинкам через `asset()` |
| [`src/pages/tutorials/tutorials.css`](../../src/pages/tutorials/tutorials.css) | Оригинальный CSS (1400+ строк), **сгенерирован скриптом**: каждое правило ограничено `.tutorials-page`, `@keyframes` с префиксом `tp-`. Сверху — блок, который внутри страницы откатывает Tailwind preflight и глобальные стили `src/index.css` (`revert`), иначе кнопки, заголовки и шрифты отличались бы от оригинала |
| `src/assets/tutorials/` | 69 картинок оригинала (≈25 МБ); Vite добавляет хэш в имена → корректный кэш |
| [`public/tutorials/index.html`](../../public/tutorials/index.html) | Заглушка: `…/tutorials/` → `…/#/tutorials` (статические серверы, GitHub Pages) |
| [`index.html`](../../index.html) | Шрифт Instrument Sans; скрипт `…/tutorials` → `#/tutorials` для серверов с SPA-fallback (Vite dev/preview) |
| [`src/App.jsx`](../../src/App.jsx) | Роут `/tutorials`; на нём не показываются общая шапка приложения и окно выбора языка (у страницы своя шапка с RU/EN) |
| [`src/data/translations.js`](../../src/data/translations.js) | `tutorials.title` — заголовок вкладки оригинала |

Тексты страницы берутся из `content.js`, а не через `t()`: страница
показывает только RU/EN и может отличаться от языка приложения (UK→RU,
ES→EN, без выбора → RU). Исключение задокументировано в `CLAUDE.md`.

### Намеренные отличия от оригинала

- `overflow-x: clip` вместо `hidden` у корня страницы: корень — `div`, а не
  `body`, и `hidden` сломал бы липкую шапку. Визуально одинаково.
- Прокрутка страницы остаётся заблокированной, пока открыт туториал. В
  оригинале закрытие лайтбокса разблокировало прокрутку под открытым окном
  (баг оригинала).
- Ссылки-заглушки `href="#"`: в футере (Privacy/Terms) прокручивают наверх,
  как оригинал; кнопки App Store / Google Play ничего не делают. В
  приложении с HashRouter `#` вёл бы на форму заявки (`#/`).
- Заголовок скрытого окна установки переводится вместе со страницей (в
  оригинале до первого показа он всегда на RU).
- Тема хранится под ключом `itrucking-theme` (в оригинале — `theme`).
- **Категории в мобильной версии (до 768px)** — по запросу после ревью.
  В оригинале это мелкие кнопки (13px), которые переносятся неровно.
  Теперь это сетка на всю ширину экрана: кнопки 48px высотой, текст 16px
  полужирный (600), иконки 20px; «Все», «Использование карт EFS» и
  «Программа скидок на шины» занимают строку целиком, «iTrucking Pro» и
  «OnRamp» стоят парой. 16px — максимум, при котором «iTrucking Pro»
  помещается в половину строки на 360px (поэтому боковые отступы 8px). Уже
  360px каждая категория занимает строку целиком. Подписи везде в одну
  строку на RU и EN (проверено на 320, 360, 375px). Ширина привязана к
  `data-category` (атрибут есть и в оригинале), а не к порядку кнопок.
  Десктоп не изменился.
- **Шапка на узких телефонах (до 480px)** — по запросу после ревью. В
  оригинале на телефонах, где видна кнопка 📱 (iOS/Android), шапка не
  помещалась: на 360px кнопка 🌙 уходила за край экрана (правый край на
  371px). Теперь меньше горизонтальные отступы у RU/EN (10px вместо 16px),
  промежуток логотип–кнопки 12px вместо 16px, логотип высотой 22px вместо
  24px. На 360–414px всё помещается с отступом 24px от края (логотип стоит
  ровно над контентом); уже 360px пропорционально уменьшается только логотип
  (на 320px — 15px), кнопки 📱 и 🌙 остаются 36×36. Проверено на 320, 360,
  375, 414px, в светлой и тёмной теме; на 1280px шапка совпадает с
  оригиналом.
- Не перенесено: `manifest.json` (в оригинале файла нет — ссылка даёт 404),
  неиспользуемые поля данных (`lang`, `icon`, статические `recommendations` —
  рекомендации и в оригинале считаются динамически), запасная «градиентная»
  обложка карточки (у всех туториалов есть картинки).

## Проверка

`npm run dev` и `npm run build` + `vite preview`, встроенный браузер, оригинал
на `python3 -m http.server 8000` рядом.

**Попиксельное сравнение.** Скрипт в обеих вкладках снимает для каждого
элемента позицию, размер, текст и 30 вычисленных стилей (шрифт, кегль,
межстрочный, цвета, отступы, рамки, радиусы, тени, display…) и сравнивает
хэши. Результат — **полное совпадение**:

| Сценарий | Элементов | Результат |
|---|---|---|
| Главная, 1280px, EN | 213 | совпадает (кроме `overflow` корня и заголовка скрытого окна установки — см. выше) |
| Главная, 1280px, RU | 238 | совпадает (кроме скрытого содержимого закрытого окна: оригинал не перерисовывает его при смене языка) |
| Все 9 туториалов, 1280px, EN | 437 | совпадает |
| Все 9 туториалов, 1280px, RU | 437 | совпадает |
| Тёмная тема: главная + туториал 5 | 326 | совпадает |
| 375px (Android): главная, 9 туториалов, окно установки | 665 | совпадает |
| То же на production-сборке (`vite preview`) | 665 | совпадает |

**Функции** (dev):
- поиск «IFTA» → 1 карточка, иконка лупы сменяется на ×; × очищает → 9;
  «zzzz» → «Ничего не найдено»;
- категории: Все 9 / iTrucking Pro 6 / OnRamp 0 («Ничего не найдено») /
  EFS 1 / шины 2;
- туториал 8 → ссылка «эту страницу» → окно закрывается и через 300 мс
  открывается туториал 9; рекомендация → туториал 8; адрес остаётся
  `#/tutorials`;
- лайтбокс: клик по картинке открывает, клик по самой картинке не
  закрывает, фон / × закрывают, src очищается через 200 мс; Esc закрывает
  и лайтбокс, и туториал (как в оригинале); клик по фону закрывает туториал;
- язык: без сохранённого языка → RU, в `localStorage` ничего не пишется,
  окно выбора языка не появляется; EN → сохраняется `en`; `uk` → RU,
  `es` → EN;
- тема: 🌙→☀️, сохраняется и восстанавливается после перезагрузки;
- уход на `#/portal` с открытым окном: шапка приложения вернулась, favicon
  и `<head>` восстановлены, прокрутка разблокирована;
- `…/tutorials`, `…/tutorials/`, `…/tutorials/index.html` → `#/tutorials`
  (preview); в dev — через скрипт в `index.html`;
- production-сборка: 0 ошибок в консоли, 0 ответов 4xx, 0 битых картинок.

`npm run build` — без ошибок и предупреждений.
